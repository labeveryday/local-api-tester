# **API Tester App**

This project is a serverless **API Tester App** built with Flask, AWS Lambda, API Gateway, CloudFront, and WAF. It allows users to test API endpoints by sending HTTP requests and viewing the responses in a user-friendly format.

## **Features**
- Send `GET`, `POST`, `PUT`, and `DELETE` requests to any API.
- Add custom headers and request bodies.
- View structured JSON responses.
- Rate limiting using **AWS WAF** to prevent abuse.
- CloudFront integration for enhanced performance and security.
- Deployed as a fully serverless app on AWS.

---

## **Architecture Overview**
The app uses the following AWS services:
- **AWS Lambda**: Hosts the Flask API tester app.
- **API Gateway**: Provides a RESTful interface to trigger the Lambda function.
- **AWS WAF**: Protects the API from DDoS attacks and enforces rate limiting.
- **CloudFront**: Serves the API via a globally distributed content delivery network (CDN) with HTTPS support.

## **Deployment**
The app is deployed using AWS SAM.

1. Upload Static Files to S3
Before deploying the app, upload your static files (e.g., index.html, main.js) to the S3 bucket:

```bash
Copy code
aws s3 sync ./static-files s3://<your-bucket-name>
```

Replace <your-bucket-name> with the actual bucket name generated by the SAM template (you’ll see this after deployment).

2. **Build the App**:
   ```bash
   sam build
   ```

3. **Deploy the App**:
   ```bash
   sam deploy --guided
   ```
   Follow the prompts:
   - **Stack name**: `api-tester-app`
   - **Region**: Select your preferred AWS region.
   - **Confirm changes**: Enter "Y" to allow SAM to create necessary AWS resources.

4. After deployment, note the **CloudFront URL** from the output. This will be your app's base URL.

## **Usage**
1. Open the **CloudFront URL** in your browser.
2. Enter the following details:
   - **URL**: The API endpoint you want to test.
   - **Method**: HTTP method (`GET`, `POST`, `PUT`, `DELETE`).
   - **Headers**: (Optional) JSON-formatted headers (e.g., `{"Content-Type": "application/json"}`).
   - **Body**: (Optional) Request body for `POST`/`PUT` methods.
3. Click **Send Request** to get the response.

---

## **Security Features**
1. **Rate Limiting**:
   - Limits excessive requests using **AWS WAF**.
   - Default: Blocks IPs sending more than 1000 requests in a 5-minute window.

2. **HTTPS Enforcement**:
   - All traffic is encrypted via CloudFront's HTTPS support.

3. **Web Application Firewall (WAF)**:
   - Protects the app from common web exploits and attacks.

---

## **Monitoring**
1. **CloudWatch Logs**:
   - Lambda logs: View function execution logs in the **AWS CloudWatch Logs** console.
   - API Gateway logs: Track incoming requests and responses.

2. **WAF Logs**:
   - View blocked IPs and traffic patterns in the **AWS WAF console**.

3. **CloudFront Metrics**:
   - Monitor request counts, cache hit rates, and latencies in the **CloudFront dashboard**.

## **Development**
1. Run the app locally:
   ```bash
   sam local start-api
   ```
   This will start a local API Gateway, allowing you to test the app at `http://127.0.0.1:3000`.

2. Modify the Flask app in the `app/` directory as needed.

## **Cost Considerations**
- **AWS Lambda**: Free tier includes 1M requests/month and 400,000 GB-seconds of compute time.
- **API Gateway**: Free tier includes 1M requests/month.
- **CloudFront**: Charged based on data transfer and request volume.
- **WAF**: Costs for rule evaluation and Web ACLs.

Monitor costs in the **AWS Billing Dashboard**.
